# About Section Videos Directory

This directory stores MP4 video files for the About section.

## Usage

Place your MP4 file in this directory (e.g., `salon-interior.mp4`) and reference it in the About component.

## Recommended Video Specifications

- Format: MP4 (H.264 codec)
- Aspect Ratio: 4:5 or similar (portrait/vertical orientation works best)
- Resolution: 800x1000 or higher
- Duration: 2-5 seconds (short loops work best)
- File Size: Keep under 3MB for optimal loading performance
